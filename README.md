# Suno Suraksha

Pehle verify karo, phir pay karo — AI-powered anti-scam copilot for Indian families.

## What is this?

Suno Suraksha ek real-time AI safety copilot hai jo deepfake/voice/WhatsApp scams detect karta hai jo Indian families ko target karte hain.

## Features

1. Upload audio, paste WhatsApp text, or upload screenshot
2. AI transcribes aur analyzes scam signals
3. Risk score (0-100) + scam category output
4. 3 tailored safe actions har scam type ke liye
5. Fraud Evidence Summary report download

## Tech Stack

- Frontend: Next.js/React (mobile-first)
- Backend: FastAPI
- Speech-to-text: Whisper (Hindi/English)
- OCR: Tesseract/Google Vision (screenshots ke liye)
- AI: LLM with structured JSON output
- Storage: Supabase
